Este sitio

Esta documentación es una web estática: HTML5, CSS3 y JavaScript sin frameworks ni proceso de compilación. Las tipografías Manrope y DM Mono se cargan desde Google Fonts. La carpeta webagenteM dentro del proyecto contiene todos sus archivos.

La tipografía Bahnschrift, usada por la interfaz del programa, viene incluida con Windows 10 y Windows 11.
